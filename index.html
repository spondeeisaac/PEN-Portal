Use PEN Field Visit as an App

For field work, install this app on the device. After it has been prepared online, you can open it from the phone home screen or computer taskbar even when internet is unavailable.
Chrome / Android / Windows: use Install PEN Field Visit App when it appears. If the button is unavailable, open the browser menu and choose Install PEN Field Visit or Add to Home screen, depending on the device.
iPhone / iPad: in Safari, tap Share → Add to Home Screen. The installed app opens without needing the normal browser tab.
Before going offline: open the app from the PEN Portal while online, confirm your schools are cached, allow Location Services, and complete one GPS test.
